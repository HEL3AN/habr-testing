# Чек-лист: Страница статьи (просмотр публикации и комментарии)

**URL-шаблон:** `https://habr.com/ru/articles/{id}/` или `https://habr.com/ru/companies/{slug}/articles/{id}/`
**Цель страницы:** просмотр содержимого публикации, взаимодействие с публикацией (голосование, закладки, поделиться), чтение и оставление комментариев.

---

## 1. Загрузка и общее отображение

- [ ] Страница статьи открывается по прямой ссылке без ошибок
- [ ] Отсутствуют ошибки 4xx/5xx в Network
- [ ] Отсутствуют ошибки JS в консоли
- [ ] При открытии несуществующей статьи (`/articles/9999999/`) корректно отображается страница 404
- [ ] Время загрузки страницы не превышает 5 секунд
- [ ] Заголовок вкладки (title) содержит название статьи

## 2. Заголовок и метаинформация

- [ ] Отображается заголовок статьи
- [ ] Отображается аватар и ник автора (кликабельны → ведут в профиль)
- [ ] Отображается дата и время публикации (с указанием тайм-зоны или относительного времени)
- [ ] Указано время чтения (если предусмотрено)
- [ ] Отображаются хабы и теги, под которыми опубликована статья
- [ ] Хабы и теги кликабельны и ведут на соответствующие страницы
- [ ] Корректно отображается тип материала (статья, перевод, туториал, новость)
- [ ] Для перевода указан оригинальный источник

## 3. Тело статьи

- [ ] Текст статьи отображается полностью, без обрезаний
- [ ] Корректно отображается форматирование (жирный, курсив, заголовки h2–h6, списки)
- [ ] Изображения загружаются и отображаются без искажений
- [ ] При клике на изображение оно открывается в полноразмерном просмотре
- [ ] Код в блоках `<code>` подсвечен синтаксически и сохраняет форматирование
- [ ] Длинные строки кода имеют горизонтальную прокрутку (не «ломают» вёрстку)
- [ ] Цитаты (`<blockquote>`) визуально выделены
- [ ] Видео (YouTube, Vimeo и т. п.) корректно встраивается и воспроизводится
- [ ] Внутренние ссылки в тексте открываются в той же вкладке, внешние — в новой
- [ ] Сноски/якоря работают корректно
- [ ] Таблицы корректно отображаются, при необходимости имеют прокрутку
- [ ] Формулы (LaTeX/MathJax), если есть, корректно рендерятся

## 4. Действия со статьёй

- [ ] Кнопка «↑» (плюс к рейтингу) увеличивает счётчик на 1 (для авторизованного пользователя)
- [ ] Кнопка «↓» (минус) уменьшает счётчик на 1
- [ ] Повторное голосование за тот же вариант отменяет голос
- [ ] Для неавторизованного пользователя при попытке голосования открывается окно авторизации
- [ ] Кнопка «В закладки» добавляет статью в закладки (изменяется состояние иконки)
- [ ] Повторный клик на «Закладки» удаляет статью из закладок
- [ ] Счётчик закладок обновляется
- [ ] Кнопка «Поделиться» открывает корректный список соцсетей / копирует ссылку
- [ ] При копировании ссылки в буфер обмена появляется уведомление

## 5. Подвал статьи

- [ ] Отображаются повторно хабы и теги
- [ ] Отображается информация об авторе (карточка с подпиской)
- [ ] Кнопка «Подписаться» на автора работает (изменяется состояние)
- [ ] Отображаются связанные/похожие публикации
- [ ] Ссылки на похожие публикации ведут на соответствующие страницы

## 6. Комментарии

- [ ] Отображается общее количество комментариев
- [ ] Комментарии отображаются в виде дерева (с вложенностью)
- [ ] У каждого комментария отображаются: автор, дата, текст, рейтинг, действия
- [ ] Ссылка на автора комментария ведёт в профиль
- [ ] Голосование за комментарий (+/−) работает для авторизованного пользователя
- [ ] Кнопка «Ответить» открывает форму ответа под нужным комментарием
- [ ] Возможна загрузка вложенных ответов («Показать ещё N ответов»)
- [ ] Свёрнутые ветви можно развернуть и наоборот
- [ ] Доступны фильтры/сортировка комментариев (по умолчанию, по рейтингу, новые, старые)
- [ ] Для неавторизованного пользователя кнопки голосования и ответа недоступны или ведут к авторизации
- [ ] Якорные ссылки на комментарий вида `#comment_{id}` корректно прокручивают к нужному комментарию

## 7. Форма добавления комментария

- [ ] Форма доступна только авторизованным пользователям
- [ ] Поле ввода поддерживает Markdown / форматирование
- [ ] Доступен предпросмотр комментария
- [ ] Невозможно отправить пустой комментарий
- [ ] Минимальная и максимальная длина комментария соблюдается
- [ ] После отправки комментарий появляется в ленте без перезагрузки страницы
- [ ] Возможно редактирование собственного комментария в течение разрешённого времени
- [ ] Возможно удаление собственного комментария

## 8. Производительность и SEO

- [ ] Оценка PageSpeed Insights (Desktop) ≥ 80
- [ ] Изображения имеют `alt`, lazy-loading работает
- [ ] Присутствуют корректные Open Graph теги для шаринга в соцсетях
- [ ] Присутствует canonical-ссылка
- [ ] URL содержит ЧПУ-идентификатор

## 9. Доступность

- [ ] Чтение текста с экранного диктора возможно
- [ ] Кнопки голосования имеют `aria-label`
- [ ] Навигация по статье возможна с клавиатуры
- [ ] Контрастность текста ≥ 4.5:1

## 10. Адаптивность

- [ ] Корректное отображение на 1920×1080
- [ ] Корректное отображение на планшете (768×1024)
- [ ] Корректное отображение на мобильном (375×667)
- [ ] Изображения масштабируются по ширине экрана
- [ ] Блоки кода не вызывают горизонтальную прокрутку всей страницы
