# Чек-лист: Поиск

**URL:** https://habr.com/ru/search/?q={query}
**Цель раздела:** поиск публикаций, авторов, компаний и хабов по введённой пользователем строке.

---

## 1. Доступ к поиску

- [ ] Иконка/поле поиска доступна в шапке на всех страницах сайта
- [ ] Клик по иконке открывает поле ввода (если оно скрыто)
- [ ] Поле поиска получает фокус автоматически при открытии
- [ ] Поиск доступен как авторизованному, так и неавторизованному пользователю
- [ ] На странице поиска URL содержит параметр запроса (`?q=...`)

## 2. Поле ввода запроса

- [ ] Поддерживается ввод латиницы
- [ ] Поддерживается ввод кириллицы
- [ ] Поддерживается ввод цифр
- [ ] Поддерживается ввод спецсимволов (`+`, `-`, `"`, `:`)
- [ ] Поддерживаются emoji (или корректно игнорируются)
- [ ] Поле принимает строку максимальной разрешённой длины
- [ ] Поле обрезает пробелы по краям (trim)
- [ ] Внутри строки сохраняются множественные пробелы или сжимаются (одно поведение, постоянно)
- [ ] Поле содержит placeholder с подсказкой
- [ ] Доступна кнопка очистки введённого текста (крестик)

## 3. Отправка запроса

- [ ] Поиск запускается по Enter
- [ ] Поиск запускается по клику на иконку/кнопку
- [ ] После отправки происходит переход на страницу результатов с корректным URL
- [ ] Пустой запрос либо не отправляется, либо ведёт на страницу с подсказкой
- [ ] Запрос из одних пробелов трактуется как пустой
- [ ] При обновлении страницы результатов запрос сохраняется в поле

## 4. Автоподсказки (autocomplete)

- [ ] При вводе появляются подсказки (если функция предусмотрена)
- [ ] Подсказки разделены по типам (статьи, авторы, хабы, компании)
- [ ] Клик по подсказке ведёт на соответствующую страницу, а не на страницу поиска
- [ ] Подсказки обновляются по мере ввода
- [ ] При отсутствии подсказок отображается соответствующее сообщение
- [ ] Подсказки доступны для навигации стрелками клавиатуры
- [ ] Escape закрывает список подсказок

## 5. Страница результатов

- [ ] Корректно отображается введённый запрос
- [ ] Отображается общее количество найденных результатов (по вкладкам)
- [ ] Доступны вкладки фильтрации результатов: «Публикации», «Хабы», «Компании», «Пользователи»
- [ ] Каждая вкладка показывает только релевантный тип результатов
- [ ] У результатов-публикаций отображаются: заголовок, превью, автор, дата, теги/хабы, статистика
- [ ] Заголовок публикации содержит подсветку совпадений (если предусмотрено)
- [ ] Клик по результату ведёт на соответствующую страницу
- [ ] При отсутствии результатов отображается понятное сообщение и подсказки по уточнению

## 6. Фильтры и сортировка

- [ ] Доступна сортировка («По релевантности», «По дате», «По рейтингу» и т. п.)
- [ ] Изменение сортировки обновляет список без полной перезагрузки
- [ ] Выбранная сортировка отражается в URL
- [ ] Доступны фильтры по дате (за всё время, год, месяц, неделя, сутки)
- [ ] Применение фильтров корректно меняет результаты
- [ ] Сброс фильтров возвращает полный список

## 7. Пагинация

- [ ] Под результатами доступна пагинация
- [ ] Переход между страницами работает без ошибок
- [ ] Номер страницы отражается в URL (`&page=N`)
- [ ] Поиск глубоко в результаты (например, 50-я страница) работает корректно или ограничен явным образом
- [ ] При запросе несуществующей страницы отображается понятное сообщение

## 8. Граничные случаи

- [ ] Запрос из 1 символа (`a`) обрабатывается (либо ищет, либо просит уточнить)
- [ ] Очень длинный запрос (~1000 символов) обрабатывается без ошибок
- [ ] Запрос с XSS-инъекцией (`<script>alert(1)</script>`) экранируется и не выполняется
- [ ] Запрос с SQL-подобной нагрузкой (`' OR 1=1 --`) обрабатывается как обычная строка
- [ ] Запрос на несуществующее слово возвращает пустой результат, а не ошибку
- [ ] Поиск с регистром (`Хабр`, `хабр`, `ХАБР`) даёт одинаковые результаты
- [ ] Поиск с опечатками (если есть fuzzy-поиск) предлагает корректные результаты
- [ ] Поиск по точной фразе в кавычках работает корректно

## 9. История поиска

- [ ] Сохраняется история недавних запросов (для авторизованного пользователя, если предусмотрено)
- [ ] Доступна возможность очистить историю поиска
- [ ] Клик по элементу истории повторяет запрос

## 10. Производительность

- [ ] Результаты поиска отображаются не дольше 3 секунд для типичного запроса
- [ ] Автоподсказки появляются с задержкой, но не дольше 500 мс
- [ ] Нет лишних повторных запросов к API при вводе (debounce работает)

## 11. Доступность

- [ ] Поле поиска имеет `aria-label`
- [ ] Кнопка поиска доступна с клавиатуры
- [ ] Результаты поиска озвучиваются скринридером (`aria-live`)
- [ ] Подсветка совпадений не нарушает читаемость текста

## 12. Адаптивность

- [ ] На мобильном поле поиска занимает удобную ширину
- [ ] Автоподсказки помещаются на экране без обрезаний
- [ ] Результаты поиска корректно отображаются на узких экранах
- [ ] Фильтры на мобильном выносятся в выпадающее меню или модалку
