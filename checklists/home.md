# Чек-лист: Главная страница (лента публикаций)

**URL:** https://habr.com/ru/
**Цель страницы:** отображение ленты публикаций, навигация по разделам и хабам, переход к материалам.

---

## 1. Загрузка и отображение страницы

- [ ] Страница открывается по URL `https://habr.com/ru/` без ошибок
- [ ] Время полной загрузки страницы не превышает 5 секунд
- [ ] Отсутствуют ошибки 4xx/5xx в консоли браузера
- [ ] Отсутствуют ошибки JavaScript в консоли
- [ ] Корректно загружается favicon
- [ ] Заголовок вкладки (title) соответствует разделу
- [ ] Корректно загружаются все шрифты (нет «прыгающего» текста — FOUT/FOIT)

## 2. Шапка сайта (header)

- [ ] Логотип Habr отображается и кликабелен (ведёт на главную)
- [ ] Отображается основное меню (Все потоки, Разработка, Администрирование, Дизайн, Менеджмент, Маркетинг, Научпоп)
- [ ] Каждый пункт меню кликабелен и ведёт на корректную страницу
- [ ] Отображается иконка/поле поиска
- [ ] Отображается кнопка/иконка уведомлений (для авторизованного пользователя)
- [ ] Отображается аватар или кнопка «Войти» (для неавторизованного пользователя)
- [ ] Шапка корректно «прилипает» (sticky) при прокрутке (если предусмотрено)

## 3. Лента публикаций

- [ ] Отображается список публикаций
- [ ] У каждой публикации присутствуют: заголовок, превью/тело, автор, дата, хабы/теги, статистика (просмотры, комментарии, рейтинг, закладки)
- [ ] Заголовок публикации кликабелен и ведёт на страницу статьи
- [ ] Аватар и ник автора кликабельны и ведут в профиль
- [ ] Хабы и теги под публикацией кликабельны
- [ ] Корректно отображается дата/время публикации
- [ ] Превью статей отображается с корректной вёрсткой (изображения не «ломают» сетку)

## 4. Фильтры и сортировка ленты

- [ ] Доступны вкладки сортировки («Все подряд», «Лучшее», по выбранному периоду)
- [ ] Переключение между вкладками меняет список без полной перезагрузки страницы
- [ ] Для «Лучшее» доступен выбор периода (сутки, неделя, месяц, год, всё время)
- [ ] Выбранный фильтр сохраняется при возврате на главную в рамках сессии
- [ ] При отсутствии публикаций отображается соответствующее сообщение

## 5. Пагинация / подгрузка

- [ ] Внизу страницы доступна пагинация или кнопка «Показать ещё»
- [ ] Переход между страницами работает без ошибок
- [ ] Номер текущей страницы отражается в URL (`?page=N` или аналог)
- [ ] При вводе несуществующей страницы (например, `?page=99999`) отображается корректное сообщение

## 6. Сайдбар (правая колонка)

- [ ] Отображаются блоки: «Лучшее за…», «Рекомендуем», топ авторов/компаний и т. п.
- [ ] Все ссылки в сайдбаре кликабельны и ведут на корректные страницы
- [ ] Рекламные блоки (если есть) не перекрывают основной контент
- [ ] Сайдбар не «уезжает» за пределы экрана при прокрутке

## 7. Подвал сайта (footer)

- [ ] Отображается полный набор ссылок (О сайте, Правила, Помощь, Реклама, Контакты, Информация для прессы и т. п.)
- [ ] Все ссылки в подвале кликабельны и ведут на корректные страницы
- [ ] Отображаются иконки соцсетей, ссылки актуальны
- [ ] Отображается копирайт с актуальным годом

## 8. Адаптивность и кросс-браузерность

- [ ] Корректное отображение на разрешениях: 1920×1080, 1440×900, 1366×768
- [ ] Корректное отображение на планшете (768×1024)
- [ ] Корректное отображение на мобильном (375×667, 414×896)
- [ ] Горизонтальная прокрутка отсутствует на всех разрешениях
- [ ] Корректное отображение в Chrome (последняя версия)
- [ ] Корректное отображение в Firefox (последняя версия)
- [ ] Корректное отображение в Edge (последняя версия)
- [ ] Корректное отображение в Safari (последняя версия)
- [ ] Корректное отображение в Yandex Browser

## 9. Доступность (a11y)

- [ ] Навигация по странице доступна с клавиатуры (Tab, Shift+Tab, Enter)
- [ ] Фокус визуально отображается на интерактивных элементах
- [ ] У интерактивных иконок присутствует `aria-label` или текстовая подпись
- [ ] Контрастность текста соответствует WCAG AA (≥ 4.5:1)
- [ ] Изображения имеют атрибут `alt`

## 10. Производительность и SEO

- [ ] Оценка PageSpeed Insights (Desktop) ≥ 80
- [ ] Оценка PageSpeed Insights (Mobile) ≥ 60
- [ ] Присутствует мета-тег `description`
- [ ] Присутствуют корректные Open Graph теги (`og:title`, `og:description`, `og:image`)
- [ ] Доступен `robots.txt`
- [ ] Доступен `sitemap.xml`
