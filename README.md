# Тестирование веб-приложения Habr

## Краткое описание проекта

Учебный проект по тестированию веб-приложения **Habr** (https://habr.com) — крупнейшего русскоязычного коллективного блога об IT, информационных технологиях, бизнесе и науке. В рамках проекта проводится функциональное, UI/UX и нефункциональное тестирование основных пользовательских сценариев сайта: регистрация и авторизация, поиск, чтение и публикация материалов, комментирование, работа с подписками и хабами, личный кабинет пользователя.

Цель проекта — выявить дефекты в работе веб-приложения, оценить удобство пользовательских сценариев и подготовить отчётную документацию по результатам тестирования.
