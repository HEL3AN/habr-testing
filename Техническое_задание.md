# Техническое задание

## 1. Объект тестирования

**Веб-приложение Habr** — https://habr.com

Habr — российский коллективный блог (контентная платформа) с элементами социальной сети, посвящённый информационным технологиям, разработке программного обеспечения, научным и научно-популярным темам, бизнесу и стартапам. Сайт работает с 2006 года, ежемесячная аудитория превышает несколько миллионов посетителей.

## 2. Цель и задачи сайта

### Цель сайта
Предоставить профессиональному IT-сообществу единую площадку для публикации, обсуждения и распространения экспертного контента, а также для обмена опытом между специалистами различных направлений.

### Задачи сайта
1. Публикация и хранение авторских статей, новостей, переводов и аналитических материалов.
2. Организация тематического деления контента (хабы, потоки, корпоративные блоги).
3. Обеспечение коммуникации между пользователями через комментарии, личные сообщения, подписки.
4. Система оценки качества контента и авторов (голосования, карма, рейтинг).
5. Поиск и фильтрация материалов по интересам пользователя.
6. Предоставление компаниям инструментов для ведения корпоративных блогов и HR-активностей (Хабр Карьера).

## 3. Целевая аудитория сайта

- **IT-специалисты:** разработчики, тестировщики, DevOps-инженеры, системные администраторы, аналитики, специалисты по информационной безопасности.
- **Технические руководители:** тимлиды, проджект-менеджеры, продакт-менеджеры, CTO.
- **Дизайнеры и UX-специалисты** в IT-сфере.
- **Студенты и начинающие специалисты** технических направлений.
- **Представители IT-компаний:** HR, маркетологи, евангелисты технологий.
- **Энтузиасты науки и технологий** без профильного образования.

Возраст основной аудитории — 20–45 лет, преимущественно с техническим высшим образованием.

## 4. Проблемы, которые решает приложение

1. **Разрозненность экспертного IT-контента** в русскоязычном сегменте интернета — Habr консолидирует материалы в одном месте.
2. **Сложность поиска качественных технических материалов** — система модерации, рейтингов и комментариев помогает фильтровать контент.
3. **Дефицит профессиональной коммуникации** для IT-специалистов на русском языке.
4. **Сложность построения личного бренда** для авторов — платформа даёт инструменты для роста аудитории и репутации (карма, рейтинг, подписчики).
5. **Поиск работы и сотрудников в IT** — через интеграцию с Хабр Карьера.
6. **Продвижение IT-продуктов и компаний** через корпоративные блоги.

**Преимущества Habr перед аналогами:**
- Самое крупное русскоязычное профессиональное IT-сообщество.
- Развитая система модерации качества (карма, инвайты — ранее).
- Глубокая интеграция с экосистемой (Хабр Карьера, Хабр Фриланс).

**Слабые стороны (потенциальные зоны тестирования):**
- Сложный для новых пользователей интерфейс с множеством разделов.
- Возможные проблемы UX в формах публикации и редактирования материалов.
- Не всегда очевидная работа фильтров и поиска.

## 6. Описание работы приложения

### Тип проекта
**Веб-приложение** (Single Page Application с серверным рендерингом). Также доступны нативные мобильные приложения для iOS и Android, но в рамках данного проекта тестируется **только веб-версия**.

### Технологический стек (по открытым данным)
- Фронтенд: JavaScript / TypeScript, серверный рендеринг
- Бэкенд: серверная часть на собственных решениях
- Доступ: через любой современный браузер (Chrome, Firefox, Edge, Safari, Yandex Browser)
- Адаптивная вёрстка для десктоп- и мобильных браузеров

### Основные функциональные модули
1. **Главная страница и ленты** — лента «Все подряд», «Лучшее», персональная лента.
2. **Регистрация и авторизация** — email, OAuth, восстановление пароля, двухфакторная аутентификация.
3. **Просмотр публикаций** — статья, комментарии, голосования, добавление в закладки.
4. **Публикация материалов** — редактор статей, черновики, выбор хабов и тегов, предпросмотр.
5. **Поиск** — по статьям, авторам, компаниям, хабам.
6. **Профиль пользователя** — настройки, подписки, опубликованные материалы, карма.
7. **Комментирование** — древовидные комментарии, голосования, цитирование.
8. **Хабы и компании** — страницы тематических разделов и корпоративных блогов.
9. **Личные сообщения** — переписка между пользователями.
10. **Уведомления** — system tray уведомлений, настройки.
